# Booth ダウンロードアプリのユーザビリティ改善案

## 1. 初回利用のガイドとステップ表示
- **課題**: メイン画面は JSON 取り込みボタンとフィルター類のみが並び、初回起動時には手順が分かりにくい。【F:BoothDownloadApp/MainWindow.xaml†L17-L62】
- **改善案**: 初回起動時にウィザードやヒントパネルを表示し、`booth_library.json` の読み込み→保存先選択→ダウンロード開始の流れを案内する。進捗バー付近に「次に行う操作」のヒントを常時表示すると迷いを減らせる。

## 2. フィルター UI の整理とプリセット
- **課題**: フィルター領域にタグ・チェックボックス・タブが縦積みされており、上限 10 件のタブを手作業で配置しているため視認性・拡張性が低い。【F:BoothDownloadApp/MainWindow.xaml†L30-L62】
- **改善案**: タブ項目をバインディングで自動生成し、タブ切り替えとタグ検索をまとめたプリセット（例: 「未DL + 更新あり」）を提供する。よく使う絞り込み条件を保存・呼び出しできるようにすると整理が進む。

## 3. ダウンロード処理のフィードバック改善
- **課題**: ダウンロードやエラーの通知がすべてモーダルの `MessageBox` で行われており、連続操作でダイアログが頻発する。【F:BoothDownloadApp/MainWindow.xaml.cs†L269-L389】
- **改善案**: ウィンドウ下部に非モーダルのログペインやトースト通知を設け、完了・警告・エラーを一覧できるようにする。失敗時はリトライや詳細ログへのリンクを提示して、ユーザーが次に取るべき行動を判断しやすくする。

## 4. リストビューの操作性向上
- **課題**: 商品一覧の `ListView` は列ヘッダーにソートやグループ化の操作が用意されていない。【F:BoothDownloadApp/MainWindow.xaml†L65-L159】
- **改善案**: 列ヘッダーをクリックした際のソート、タグ・ショップ単位でのグルーピング、列の表示・非表示切り替えを実装することで大量のアイテムでも目的の項目に素早くアクセスできる。

## 5. 保存先フォルダー表示の改善
- **課題**: ダウンロード先パスが固定幅 200px のテキストブロックで表示され、長いパスが省略されてしまう。【F:BoothDownloadApp/MainWindow.xaml†L168-L185】
- **改善案**: ツールチップでフルパスを表示し、コピー・履歴から選択できるドロップダウンを用意する。よく使うフォルダーをお気に入り登録できると再設定が容易になる。

## 6. Chrome 拡張機能利用時の制限整理
- **課題**: ライブラリ取得用の Chrome 拡張機能はログイン済みの Booth ライブラリ／ギフトページでのみ動作し、タグ情報は収集せず、利用には手動でのアンパック読み込みが必要となる。【F:booth-scraper-extension/README.md†L1-L18】
- **改善案**: アプリ内に拡張機能セットアップ手順と注意点（対応ブラウザー、必要ページ、取得できない情報など）をまとめたヘルプを用意し、可能であれば拡張機能をストア配布するか、アプリ側から JSON 取得までガイドすることで利用時のつまずきを減らす。
